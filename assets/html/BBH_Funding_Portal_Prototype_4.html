About This Prototype

This is an interactive demonstration of the BBH customer-facing funding portal — the answer to the question "where can the technical team find the payment portal?" The portal lives inside the BBH customer app.

Two flows covered

  • Account Linking (API 7.1, gated by 3.1/3.2). Customer establishes a verified link between their Al-Taif Islamic Bank account and their BBH wallet. OTP-gated: TIB sends a code to the phone on file for the TIB account; customer must enter it before BBH calls POST /accounts/verify. One-time setup. Required before in-app funding can be used.
  • Funding · Instant Transfer (API 4.3 + 3.1/3.2). Customer moves money from their linked TIB account into BBH's segregated client account, confirmed via TIB-issued OTP. The single funding path.

How to use

  • Click buttons inside the phone to advance the flow.
  • Watch the API Activity panel on the right — every step that involves a TIB API call or webhook is logged.
  • The annotation bar at the bottom explains what's happening at each screen in plain language.
  • Switch flows using the tabs at the top.
  • Use Reset to return to initial state (no linked account, zero balance).

Who builds what

Everything inside the phone is BBH's app — BBH builds the screens, copy, and UX. The right-hand API panel shows the TIB endpoints being called behind the scenes. TIB owns those APIs and the money rails; BBH owns the customer experience.

Status

Prototype only — no real money moves, no real TIB endpoint is called. All amounts, account numbers, customer IDs, and OTP codes are fixed demo values.
